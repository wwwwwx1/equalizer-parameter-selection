# 新电脑训练用移植包

**新增模型配置编辑、两种MATLAB仿真与结果分析页面。** 已携带原仿真脚本快照和两个信道处理依赖函数；在新电脑选择其matlab.exe即可尝试运行，需要对应工具箱和许可。原始MATLAB脚本模板内的旧路径会在工作台生成运行副本时替换，不直接使用。说明见 [MATLAB集成用法](docs/模型配置与MATLAB集成使用说明.md)。

**新增统一界面：打开统一工作台.vbs。** 数据准备、模型训练、单信道预测、批量预测在同一窗口切换，扫描和训练显示实时进度。离线电脑已有Python时，只需在根目录`python_path.txt`填写已有`python.exe`完整路径，再双击启动，无需先运行联网安装脚本。见 [统一工作台说明](docs/统一工作台使用说明.md)。

这份代码包用于：**新电脑自己的信道与网格结果 → 从头训练 → 输出模型与训练图 → 预测其他信道的参数。**

没有携带旧电脑的110个信道、旧标签、旧候选表或旧模型权重。默认原始主径为第501列，变量名为`h_vary`，目标为MeanCodedBER，全部新数据用于训练。

先阅读这两个文件：

- **迁移与操作说明.md**：环境安装、填写新目录、准备数据、训练、预测、常见错误。
- **当前模型详细说明.md**：模型结构、张量尺寸、特征、损失、训练逻辑和可修改位置。

建议操作顺序：

1. 将整个`_移植`文件夹复制到新电脑，可改文件夹名称，但保持内部结构。
2. 建立项目内`.venv`环境。只有CPU时可双击`01_安装CPU环境.cmd`；使用GPU请先按详细说明安装对应PyTorch。
3. 编辑`configs/dataset.json`中的`channel_dir`与`result_dir`，填新电脑的两个真实目录。
4. 双击`02_检查并准备数据.cmd`。
5. 双击`03_训练并出图.cmd`。
6. 训练完成后双击`04_打开预测窗口.vbs`。

第一次使用前也可双击`05_软件自检.cmd`，测试只使用临时合成样本，结束后清理，不是正式训练。

当前包适配原项目同类MAT结构：结果包含`currName`、`currSNR`、`param_delt`、`param_N1`、`param_N2`、`coded_ber_after_mc`；原始信道包含`h_vary`。如果新结果结构不同，需要修改字段映射或适配函数，不能只更改变量标签来猜测对应关系。
