# 消融与多模型工作台使用说明

双击项目根目录“打开统一工作台.vbs”，进入新增的“消融与多模型”页。

## 在新电脑重新训练

1. 先到“数据准备”页，用新电脑自己的信道文件和网格结果生成索引。标签必须为 MeanCodedBER，SNR必须是对应仿真的真实值。
2. 到“模型训练”页确认索引CSV、候选参数CSV、轮数、每批样本、缓存和主径。新电脑原始主径为501；已裁剪数据勾选“索引指向已裁剪信道”。裁剪选项沿用训练页，不读取旧电脑数据。
3. 在“模型配置”页设置共享网络与损失参数，点击应用。每个消融变体都从这份配置复制，再应用选中变体的修改；任务配置保存后不会随界面再次编辑而变化。
4. 到“消融与多模型”页，按Ctrl或Shift选择多个模型。完整模型是共同参照；带“无功率”的变体属于无功率条件下的实验，不能把它们与完整模型的差异全部归因于另一组件。
5. 设置训练种子（如42,43,44）、划分种子和并发数，再点击窗口下方“开始当前页任务”。每个模型×每个种子分别启动独立训练进程。默认并发1；并发2代表最多两个任务同时训练，其余等待。共享一张GPU时并发会增加显存需求，显存不足的任务标记失败，查看对应日志并降低并发或批次后重新运行。

## 两种实验模式

- 组外比较：按channel_source_id统一生成约70%训练、20%验证、10%测试的来源组划分。至少需要3组。所有模型和训练种子共享划分；标准化和固定参数仅使用训练子集。验证集选择权重，训练结束才读取测试指标。当前界面版本采用一次来源组留出，不是历史实验的3折协议，结果不能直接混合比较。
- 全量训练：本次实验独立索引全部标为train，原索引不变。所有样本用于训练，结果明确显示“训练拟合”，不能解释为新信道性能。用于确定结构之后训练可部署模型。

设置多个训练种子能看到训练随机性。改变划分种子会新建一套实验。结构不同即使设置同一随机种子也不能保证每个共有层初始化逐元素一致。本界面使用统一训练引擎（含学习率调度和验证选模），与此前固定30轮消融脚本的协议不同。

## 查看进度与比较

任务表自动刷新状态、已完成轮数、Loss、BER、固定参数BER、Regret和Top1。训练中显示验证指标或拟合指标，完成后组外模式显示测试指标。

选中一行可打开该模型独立日志。扫描数据、训练批次的更细进度在日志中；首轮尚未完成时轮数和曲线为空。选中多行点击“对比所选曲线”，显示损失、验证/拟合BER、Regret和Top1。未选行时比较本实验全部任务。“最终BER对比图”只比较已完成模型，并显示训练集选出的固定参数基线。

点击“使用所选模型预测”将该模型填入窗口顶部并跳到单信道预测；批量预测也使用顶部同一模型。此按钮不改项目全局默认模型文件。组外模型只训练了训练子集，正式部署可用选定结构重新全量训练。

## 文件保存

每次实验保存在结果根目录下独立时间戳文件夹：

- experiment.json：共享配置、变体、种子、并发数与评估模式。
- index.csv：本次实验的统一划分和绝对数据路径。
- tasks.json、各任务JSON：完整任务与模型配置快照。
- 各任务.log / .status.json / .progress.json：日志和运行状态；某个任务失败不影响其他任务完成。
- 每个模型_seed目录：training_history.csv、模型权重、figures训练图、result.json；组外模式另有evaluation测试指标和逐样本预测。
- comparison.csv：所有成功任务的最终比较表（不把拟合结果标为测试结果）。
- 对比窗口打开时保存selected_training_comparison.png或selected_final_comparison.png。

可用“选择历史实验”加载含tasks.json的目录，查看过去本工作台实验。旧版ablation_v1/v2只有折权重，没有每轮训练记录，不能据此恢复不存在的训练曲线。

移植时复制本项目代码和配置；在新电脑重新指定Python解释器、数据路径。移植包不需要当前电脑的历史实验结果。此次功能使用原有PyTorch、NumPy、Matplotlib和Tkinter，没有新增第三方依赖。


普通“模型训练”页现已默认按来源组7:2:1划分，原始索引不变。划分索引与split_summary.json保存在本次输出目录同级的_split目录；报告记录实际样本数和来源组数。验证集选最佳轮次，测试集仅在训练结束评估，测试结果保存在evaluation/test_metrics.json。多模型组外模式采用相同比例；全量训练仍是明确选择的可选模式。组大小不同或独立组数少时，实际样本比例可能偏离7:2:1。
