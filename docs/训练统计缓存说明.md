# 训练统计缓存说明

每次新建训练时，模型需要根据**训练集**计算两类固定量：

- SNR 与信道能量的归一化均值、标准差；
- 294 组候选参数中训练集平均 `MeanCodedBER` 最低的固定参数基线。

这些量与网络层数、学习率、训练轮数无关。只要训练信道、训练/验证/测试划分、候选参数表和信道裁剪配置没有改变，工作台会自动复用 `cache/training_statistics/` 中的缓存，跳过这一次逐 MAT 文件扫描。

首次使用某一数据集组合时仍需要扫描，结束后控制台会显示“已写入训练统计缓存”。后续同一数据集的新试验会显示“复用训练统计缓存”。

## 何时自动重新扫描

缓存键会检查训练样本清单、原始信道和结果文件的大小与修改时间、候选表、主径位置、时间/时延裁剪、特征与字段配置。因此修改数据、重新划分数据集、从主径 626 改为 501，或替换 MAT 文件后，都会自动建立新缓存，不会错误沿用旧统计量。

## 工作台配置

在“模型配置”页面可看到 `reuse_training_statistics`。保持 `true` 即可。`training_statistics_cache_dir` 默认是 `cache/training_statistics`，通常不需要修改。

这项缓存只减少每次新训练开始前的预扫描时间；每个 epoch 仍需要读取训练样本并进行前向、反向传播。对于数千个大 MAT 文件，请保持“内存缓存特征”关闭，避免占满内存。
