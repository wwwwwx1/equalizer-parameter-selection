# 训练诊断与调参

重新打开工作台，新训练会保存 diagnostic_history.csv。点击“中途曲线”并选择当前模型输出目录，会同时打开逐batch曲线和完整训练诊断面板。诊断面板每10秒刷新。完成训练后 figures/diagnostics.png、pdf、svg自动生成，使用工具栏可放大或另存。

## 面板中的指标

- BER：固定训练监测子集、完整验证集及各自固定参数基线。下降才表示选参代价改善。
- 平均Regret、P90 Regret：整体与较差样本距离网格最优还有多远。
- Top1/3/5：推荐列表包含网格最优的比例，不能替代实际BER。
- 原始回归、软标签、期望Regret、排序损失：轮末eval模式下按固定定义计算，不乘随epoch变化的权重。训练/验证可直接比较；其中排序采用固定随机参数对。
- 加权训练贡献：实际参与优化的各项损失。权重渐增可能导致数值升高，不直接表示学差了。
- 学习率：本轮真正使用的学习率；training_history.csv原learning_rate列为调度后的下一轮值。
- 梯度范数与裁剪比例：频繁裁剪可提示更新过大，但不是故障结论。AMP非有限梯度通过跳步处理，另记录跳过批次数与缩放。
- 优于/差于固定参数的样本比例：同时看改善覆盖率与退化比例。
- 本轮时间及GPU峰值已分配显存：包含训练和评估；不是GPU利用率或总显存占用。CPU时GPU显存为0。
- 附加损失权重进度：用于解释预热与渐增阶段。

diagnostic_history.csv还保留分布熵、分类损失等数值。latest_validation_scores.npz保存最近完成轮次的分数和BER矩阵（全量训练时scope为fit），旧轮次不重复保存大矩阵。

## 如何看过拟合

若训练监测BER降低而验证BER升高，可能过拟合。diagnostic_status.json会根据最近三轮端点给出提示，但它不是显著性检验，来源组差异也可能造成差距。必须结合完整趋势判断，不能仅凭一轮波动。没有验证集时明确提示无法判断泛化。

默认training.monitor_samples为128；0代表监测整个训练集。采样仅从训练集选取，固定名单保存在monitor_samples.json。监测子集可能不能代表所有训练样本，监测量越大耗时越长。测试集不参与每轮诊断。旧历史没有记录的指标无法补造；恢复旧断点后从新完成的轮次开始记录诊断。
