# 外部模型测试工作台

## 移植版首次使用

本移植包已包含自定义固定参数、独立绘图和“指标—结果”表格。没有复制本地110信道、模型权重或测试结果。配置中的模型、信道、294组结果路径留空，请在窗口选择新电脑上的文件。

移植版原始主径默认501，时间窗口从所选模型读取；默认不允许短记录。下文提到本地110信道主径626、15条短记录仅为旧测试示例，不能直接套用新数据。按新电脑实际信道情况修改。

输出默认位于本项目“测试完成模型/测试结果”，可在窗口修改为绝对路径。python_path.txt填写新电脑已经安装依赖的Python路径，保留该电脑现有环境配置，不需要在线下载。

若只更新旧项目，复制scripts/external_model_test.py、scripts/external_test_gui.py、打开模型测试工作台.cmd、docs/外部模型测试工作台说明.md。首次添加时还需复制configs/external_test.json；已有此配置且保存了新电脑路径时，请保留原配置。依赖使用原项目的nlms_dfe及scripts/prepare_data.py，不要只把窗口脚本单独拿出去运行。

双击项目根目录的“打开模型测试工作台.cmd”。它使用python_path.txt指定的现有Python，不需要下载依赖。也可以在项目目录终端执行 `python -m scripts.external_test_gui`，前提是已选中项目Python环境。

## 操作

1. 选择模型PT：优先best.pt（验证集选择的最佳模型），也可选择last.pt（最近完整轮次）。窗口按checkpoint自带结构加载，无需修改训练配置；新模型必须仍由本项目支持，且保留state_dict、config、candidates、candidate_ids、fixed_index字段。
2. 选择原始信道MAT目录和294组grid结果目录。信道按文件名与结果currName严格匹配，缺失或重复就报错；不会随机填写SNR。
3. 本地110信道原始主径填626；其他数据按实际主径填写，例如501。原始时延窗口由主径±250确定。时间范围、特征、池化等沿用模型配置。
4. 本次110信道含短记录，因此启用“不足4000行时取到实际末尾”。如需严格相同长度，关闭该选项；越界会报错。已裁剪输入仅在确实预裁剪过时勾选。
5. 输出目录默认“测试完成模型/测试结果”。点击开始测试，日志显示每个样本的进度与BER；每次新建时间戳子目录，不覆盖旧结果。
6. 更换模型后重复上述步骤即可。不要在运行中修改路径来期望影响本次任务；设置只对新任务生效。停止会保留已写CSV，部分结果不代表完整测试。

## 评估口径

## 自定义固定参数与单独绘图

窗口新增“指标—结果”表格。测试完成、选择已有完整结果目录、点击“加载指标表”，或自定义基线绘图完成后都会显示对应指标。表格包含信道数、固定组合、模型/固定/网格最低平均BER、相对改善、优于/差于/持平数量、Top-1/3/5、平均及P90 regret。相对改善为负表示模型更差。表格标题标明当前读取目录；仅修改输入框而未运行不会改变已保存的结果。

- 不勾选“自定义固定参数”：新测试使用模型训练时选定的基线；重画旧结果使用该结果原来的基线。
- 勾选后填写mu、N1、N2。组合必须存在于294组候选表，程序按参数值匹配，不按编号猜测。新测试的CSV、MAT、报告、指标和图都会使用指定基线，并记录user_specified来源。
- 只想画图时，选择“已完成测试结果目录”，必须是含metrics.json、predictions.csv、scores_and_ber.npz的单次时间戳目录，然后点击“绘制结果图”。不需要重新读取原始信道或加载模型。
- 重画时也可勾选自定义固定参数：利用保存的全部候选BER重新计算固定BER、改善比例和差值分布，模型预测保持不变。每次图输出在所选目录的plots/新时间戳下，包含PNG/PDF/SVG、comparison_metrics.json和逐信道comparison.csv，不覆盖原报告或MAT。
- 新测试完成后自动填写本次目录；绘图结束自动打开图所在文件夹。原始测试仍会自动生成对比图，按钮用于再次导出或更换固定基线。
- 同一批测试数据反复选出表现最好的固定组合属于事后比较，报告时应明确说明，不等同于预先确定的部署基线。

## 数据与基线来源

输入SNR读取currSNR。标签使用coded_ber_after_mc按重复次数求均值，并与同名CSV的MeanCodedBER核对。模型候选与结果候选按mu/N1/N2匹配，不能仅相信编号一致。

固定基线默认来自模型训练checkpoint，也可以由用户明确指定，不自动在110信道上寻找最优固定组合。网格最低值仅是已有294组表中的参考，不作为预测输入。

这是离线预测查表，不是重新运行均衡器仿真。新旧仿真协议、采样率、信道幅度尺度、时域窗口等是否一致，需要研究者核对。文件身份匹配不能证明来源独立；报告不自动声称独立测试。若反复根据110数据修改模型，应把它作为开发验证集，最终另留测试数据。

不需要重新训练或读取新电脑失效的训练数据绝对路径。若新架构无法被ParameterSelector加载，会明确报错，需同步新架构代码，不能用旧代码强行加载。

首次不允许短记录的运行会在遇到短信道时报错，留下部分CSV；仅包含metrics.json与测试报告的成功目录才是全量完成结果。
