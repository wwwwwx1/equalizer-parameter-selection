# 诊断输出和逐图解读

完整面板为4行3列，以下编号按从左至右、从上至下排列。横轴均为epoch。train指固定训练监测子集（默认最多128个样本），val指完整验证集。二者均在轮末、关闭dropout的eval模式计算。没有验证集的全量训练不显示val曲线。

实时“epoch / batch曲线”左上角在新版中显示固定定义的完整目标：每轮都按全部辅助损失已启用的相同权重重新计算，因此可以横向看收敛趋势。它不一定趋近零，因为软标签交叉熵与排序项本身可以有非零下界。左下角的batch总目标仍会经过预热和渐增阶段，只用来排查波动，不能跨阶段判断收敛。

## 1．BER与固定参数基线

train_ber、val_ber是推荐参数的MeanCodedBER；train_fixed、val_fixed是训练集选择的同一固定参数在相应集合的BER。图中0.04代表4%。各集合难度不同，固定基线数值可以不同。

先看验证BER是否低于验证固定基线，再看是否持续改善。训练BER下降而验证BER持续上升是可能过拟合的信号；两者都不下降也可能是优化困难或数据问题，不能仅归因于欠拟合。

## 2．平均Regret与P90 Regret

每条信道Regret＝推荐参数BER−该信道网格最低BER。平均值反映整体差距；P90为90%分位数，反映较差样本的差距，不能理解为最差10%的平均值。越低越好。平均下降但P90升高说明部分较差样本仍值得检查。

## 3．Top-1、Top-3、Top-5

推荐前k项中包含网格最优参数的样本比例。0.4代表40%。命中率不衡量选错时的代价，所以必须结合BER和Regret。当前图展示训练Top1/3和验证Top1/3/5，训练Top5也保存在CSV。诊断计算使用1e-8并列容差；正式评估使用配置中的tie_tolerance，修改该配置时两者可能略有差异。

## 4．原始回归损失

比较预测分数与按每个样本BER跨度归一化的性能差距，使用Smooth L1。没有乘训练权重。训练与验证曲线同定义，比跨阶段总Loss更适合观察收敛。数值不是物理BER。

## 5．原始软标签交叉熵

衡量预测推荐分布与BER生成的软目标分布的匹配程度。越低通常越好，但软目标具有熵，最优值不必为0。即使训练中关闭此项，诊断仍可计算它作为辅助观察。

## 6．原始期望Regret损失与排序损失

regret_loss是推荐概率下的归一化期望代价，与第2图的最终单一选参Regret不同。rank是固定抽样候选对的排序损失；每轮使用相同候选对，减少测量随机波动。两种数值不能直接比较大小，也不能因某项较大就判定它更重要。

## 7．加权训练损失贡献

显示实际优化过程中各batch的样本加权平均贡献，包括预热和渐增权重。这里不是轮末eval值。某项上升可能来自权重增加，要结合原始分项与第12图判断。分类变体主要使用classification项；不能把不同目标的总Loss数值拿来给模型排名。

## 8．实际学习率

lr_used是本轮更新真正使用的学习率，不是下一轮调度后的值。它不是NLMS步长mu。学习率较小不自动表示不好；结合验证BER与梯度观察是否停滞。自动减半表示触发调度条件，不代表一定改善。

## 9．裁剪前梯度范数与裁剪比例

grad_norm_mean为批次梯度范数有限值的平均；clip_fraction为超过裁剪阈值的批次比例。两种数值单位不同，同图不能比较曲线高度。频繁裁剪可提示梯度较大，但不能单凭此结论增大学习率。非有限梯度不计入范数均值，应结合AMP跳步检查。

## 10．优于／差于固定参数的比例

better、worse为对应样本比例，其余为持平。多数样本略有改善、少数样本严重退化时，平均BER仍可能变差，因此不要只看胜率。

## 11．耗时与显存

seconds为截至诊断记录时的本轮墙钟时间，包含训练、验证和训练监测评估，不包含之后所有保存操作；暂停时间也可能计入。peak_gpu_mb为本轮PyTorch峰值已分配GPU显存，单位MiB，不是GPU利用率，也不是系统总显存。两条线单位不同，不能直接比较高度。CPU运行显存值为0。

## 12．AMP跳步与附加损失权重

amp_skipped_batches通过AMP缩放下降统计跳步次数；偶发可能是动态缩放调整，持续发生应检查数值稳定性。weighted_auxiliary_weight是附加损失系数：预热为0，随后渐增到1。它与跳步次数不是同一量纲。AMP缩放本身另外保存在CSV。

## 其他输出

| 文件 | 内容 |
|---|---|
| diagnostic_history.csv | 每轮固定口径指标、加权贡献、熵、分类损失、梯度、学习率与资源信息 |
| diagnostic_status.json | 简单趋势提示：比较当前与三轮前的训练/验证BER；不是显著性检验 |
| monitor_samples.json | 固定训练监测样本名单 |
| training_history.csv | 每轮优化Loss、验证或拟合指标、调度后的学习率及耗时 |
| batch_history.csv | 每batch损失、加权分量、学习率及阶段；实时窗口显示最近3000批和20批滑动平均 |
| latest_validation_scores.npz | 最近轮次分数和BER矩阵；全量模式标为fit，不是测试数据 |
| figures/diagnostics.png、pdf、svg | 12图完整面板 |
| figures/诊断图逐图解读.md | 随图导出的本说明 |
| evaluation/test_metrics.json、test_predictions.csv | 组外训练结束后最佳模型的独立测试指标、逐样本推荐结果；不用于每轮调参 |

旧训练没有记录的历史变量不会凭空补出。过拟合提示只提供线索，固定训练子集与验证集分布差异也会造成曲线分离。不要把测试集加入实时调参曲线。
