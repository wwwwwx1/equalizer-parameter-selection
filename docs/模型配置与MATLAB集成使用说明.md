# 模型配置、MATLAB仿真与绘图分析

关闭旧窗口，重新双击“打开统一工作台.vbs”。原来的四个页面保留，并新增模型配置、预测参数MATLAB仿真、294组MATLAB仿真和仿真结果分析，共八个页面。

## 一、可视化修改模型

进入“模型配置”，配置按data/model/loss/training等分组展开，当前值和部分含义直接显示。双击具体条目修改；布尔值用true/false，列表使用JSON形式。

页面顶部预览Transformer层数、宽度、头数、FFN维度和候选头形式。修改后点“应用到训练页”，会校验关键维度和目标字段，保存一份新的JSON，再把设置带到训练页。也可单独“另存配置JSON”。这不会改变正在使用的模型权重，必须重新训练后才获得对应结构的权重。

“从训练页刷新”可载入当前准备的索引与参数。若修改了d_model，必须保证是偶数且能被heads整除；层数、批次等应为正整数，dropout在[0,1)。当前工作台目标保持MeanCodedBER。

## 二、在工作台运行MATLAB

两页均可选择：

- MATLAB程序：本机已检测到R2023b，路径为D:/MATLAB/bin/matlab.exe。其他电脑选择自己的matlab.exe。
- 原始脚本：默认使用提供脚本的项目内快照；可以选择相同结构的更新脚本。
- 依赖目录：默认项目内matlab_integration/dependencies，包含shift_H_pd与shift_H_pd_all。
- 预测清单MAT：包含channel_names/channel_paths/snr_db，预测仿真还使用mu/N1/N2等。
- 结果MAT完整路径：可自行指定目录与文件名。文件已存在时拒绝覆盖。
- MC次数、原始主径列号、随机种子、是否并行、只跑前N个信道。

N=0表示全部；建议第一次用N=1、MC=1检查路径和协议，再改成正式次数。当前294页仍遍历完整294候选，不因试运行而缩小网格。

**294组脚本并不是单纯选一个原始信道文件夹就能运行。** 它从同一份预测清单读取信道名、原始路径和SNR，忽略预测参数，再遍历全部候选。这样两种仿真可以使用同一份信道/SNR清单。原始信道仍从清单中保存的路径读取，迁移后应确保这些路径有效。

点击“开始当前页任务”后，工作台通过matlab -batch运行，输出日志和逐信道进度。需要新电脑具备MATLAB和通信、信号处理工具箱；并行选项还需要并行计算支持。Python环境本身不能替代MATLAB许可。

### 原脚本如何保留

不修改外部两个原始.m文件。每次运行创建“结果文件名_workbench”文件夹，保存配置JSON、参数化脚本副本、MATLAB日志和完成状态。替换的内容是输入/输出路径、依赖目录、MC、主径、种子、串行/并行、试运行信道数和保存调用；NLMS-DFE-DPLL、波形与接收机计算主体保持原逻辑。

工作台现在会在这个目录名后自动增加运行时间，例如`results_workbench_20260908_201530_123456`。因此，即使上一次运行失败留下日志，再次运行也不会因日志目录重名而停止。结果MAT文件本身仍不会覆盖：若您指定的结果MAT已经存在，需在窗口中选择一个新的结果文件名。

原脚本若结构大幅变化，适配器可能提示找不到替换位置并停止。此时应调整scripts/matlab_bridge.py，而不是忽略报错。模板内原始路径只用于保持来源快照；请通过工作台运行，不要直接运行模板文件。

时域处理沿用MATLAB原脚本的h_vary(626:end,:)与实际动态卷积访问规则；本次没有擅自改成神经网络的626:4000输入窗口。两者的决策时序仍需在研究中单独说明。

## 三、保存类型和内容

可以选择MAT v7.3或v7；大数组推荐v7.3。还可另外导出存在的汇总表/网格总表为CSV或XLSX。

内容复选项包括：译码前MC BER、译码后MC BER、MSE、保存的信道H、发送/编码序列、完整网格表、汇总表。默认保留原脚本的主要完整结果，便于后续分析。

关闭某一项是对保存内容的筛选，不是停止计算该指标。例如关闭Decoded MC仅不保存其原始数组，原脚本仍按原来接收链计算。汇总表中的统计量也可能仍存在，不能把“不存明细”等同于“该指标从未计算”。

“额外变量名”可填写逗号分隔的MATLAB工作区变量名，例如rx_clean。只能保存该次保存时实际存在的变量；未生成的名称记录于workbench_missing_extra_variables和最终状态，不会伪造值。

**额外工作区变量不自动变成每个信道都保存一份的数组。** 例如最终rx_clean通常是最后一个处理信道的波形。如果将来要保存每个信道的接收波形、每个MC的噪声或每轮抽头演化，需要在MATLAB计算循环中明确积累这些变量，再选择保存。界面已经提供可扩展的变量入口。

“全部工作区变量”可能产生非常大的MAT，尤其h_vary_pd等大矩阵；只在确实需要调试完整工作区时选择。

## 四、预测到仿真再到分析

1. 在“批量预测”完成信道预测，汇总MAT路径会自动填入两个MATLAB页面和分析页面。
2. 在“预测参数MATLAB仿真”选择输出路径后运行，结果路径自动填入分析页。
3. 在“294组MATLAB仿真”选择另一输出路径，运行同一份输入清单，结果也会自动填入分析页。
4. 进入“仿真结果分析”，核对三份MAT，选择分析输出根目录，再点击开始。

单信道预测原有的prediction.mat仅包含单组参数，尚不是这两个批量MATLAB脚本要求的清单格式。需要模拟一个信道时，可在批量预测目录中只放该信道，或从已有批量清单使用“只跑前1个信道”。

## 五、对比分析的口径

分析页面支持任意实际信道数量，不再固定26个。会核对信道名唯一性、SNR、参数映射、可用的协议/发送序列，以及保存的H。失败、缺失记录写排除CSV并计数，全部无效时停止。

固定参数默认从顶部模型的checkpoint读取训练阶段确定的固定三元组；也可显式填写mu,N1,N2。固定参数不在当前网格时会报错。网格固定参数排名是本批次事后统计，不冒充训练集基线。

主要配对比较从同一网格MC矩阵抽取预测候选，因此该候选和固定参数共享相同网格内噪声。单独运行的预测仿真原值另外保留；两脚本即便rng种子相同，也不自动认定逐次噪声一致，尤其启用parfor时。

如果保存时关闭了译码前MC明细，就不能完成完整的共同噪声分析，程序会提示缺字段。关闭Decoded明细时仍可进行主要Coded分析，只省略对应辅助图。建议正式验证保留完整MC、参数与元信息。

分析输出：

- 逐信道对比、异常信道排序、策略汇总、完整网格固定参数排名。
- 原始平均网格矩阵与关键策略数组NPZ。
- 数据核验JSON与明确的排除记录。
- 六类图：译码前BER、配对差值、SNR与regret、译码后辅助BER、低误码对数细节/零值标记、参数组合对照。
- Markdown与可直接打开的HTML报告，图同时保存PNG/PDF/SVG。

此通用入口保留了原“验证”目录的核心对比逻辑，但不会机械套用旧报告中固定26信道、旧训练重叠检查或旧结论。它也没有自动生成旧报告全部的MC五折与复杂统计检验。新输出属于当前文件的描述性分析，不能直接当作泛化或显著性证明。

## 六、已经验证的范围

本机实际运行通过：一个信道、MC=1的预测参数仿真；一个信道、MC=1的全部294候选仿真；选择性保存为MAT v7并导出CSV/XLSX；额外变量保存及缺失记录。
