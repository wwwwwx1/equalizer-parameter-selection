# 统一工作台更新记录

本次新增统一窗口，包含数据准备、模型训练、单信道预测、批量预测四个标签页。两种预测共用当前模型入口，训练完成后更新该入口。仍默认MeanCodedBER、主径501、使用新电脑自己的数据从头训练。

移植目录仍未携带旧训练数据和旧模型。没有因为界面升级而重训本地真实模型。旧代码入口保留，推荐以后使用打开统一工作台.vbs。
